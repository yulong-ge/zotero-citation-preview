# Reader integration architecture

A `MutationObserver` watches the reader document for native popovers. The plugin reads native popup state, then appends its metadata section. It does not replace native pointer handlers, hit-testing methods, popup callbacks, delay timers or selected-overlay state.

There are no pointer-move listeners, periodic scans, OCR or background indexing. Named-citation handling reads the selected source and bibliography pages through Zotero's PDF worker. Page data has an eight-page cache per document; metadata has a 128-entry memory cache. Each open native popover has a foreground lookup and at most one background lookup. The background queue prefetches only the other references in that open group. A popup-local map shares pending, completed and failed lookups by bibliography text; selecting a queued entry starts it in the foreground and cancels the previous foreground lookup. Selecting an in-flight prefetch reuses it. Closing the popup cancels both streams and prevents queued work or late cache writes. Each failed prefetch is marked on its numbered choice and shown in full when selected; failures are not retried automatically. Requests use privileged `Zotero.HTTP.request`, anonymous mode and a 12-second timeout. Reader unload and addon disable remove the enhancement and observer.

`Zotero.CitationPreview.metrics` records requests, cache hits, prefetches, prefetch reuse, page reads, DOM construction and observer time. `await Zotero.CitationPreview.measureResponsiveness({durationMs:5000,intervalMs:50})` measures event-loop timer delay when explicitly invoked. These metrics do not measure browser paint.
